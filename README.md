# ShootingGame

Unityで制作した2Dシューティングゲームです。宇宙船を操作して、右から迫ってくる敵(隕石)を撃ち落とし、ハイスコアを目指します。

## ▶ 今すぐ遊ぶ

 **https://inoueharuto42.github.io/ShootingGame/**

## ゲームの特徴

- **シンプルな横スクロール型シューティング** — 敵は画面右端のランダムな高さから一定間隔で出現し、左に向かって迫ってきます
- **スコアシステム** — 弾を敵に命中させると敵が爆発し、スコアが1点加算されます。スコアは画面に常時表示されます
- **ゲームオーバーとリトライ** — 敵に接触するとゲームオーバー画面へ移行し、最終スコアが表示されます。「New Game」ボタンからすぐに再挑戦できます
- **サウンドとエフェクト** — 射撃音・爆発音、被弾時の爆発アニメーションを実装しています

## 操作方法

| 操作 | キー |
|------|------|
| 移動(上下左右) | 矢印キー または WASD |
| 弾を発射 | スペースキー |

## 動作環境・開発環境

- Unity **6000.3.11f1** (Unity 6)
- 2D プロジェクト(Universal Render Pipeline)

## プロジェクトの開き方

1. このリポジトリをクローンします
   ```bash
   git clone https://github.com/InoueHaruto42/ShootingGame.git
   ```
2. Unity Hub で「Add」→ クローンしたフォルダを選択します
3. Unity 6000.3.11f1(または互換バージョン)で開きます
4. `Assets/Scenes/MainScene.unity` を開いて再生ボタンを押すとゲームが始まります

## プロジェクト構成

```
Assets/
├── Scenes/       # MainScene(ゲーム本編)、GameOver(ゲームオーバー画面)
├── Scripts/      # プレイヤー・敵・弾・スコア管理などのC#スクリプト
├── Prefabs/      # 弾・敵・爆発エフェクト・背景のプレハブ
└── Space Shooter Assets/  # スプライト・効果音などのアートアセット
```

### 主なスクリプト

- `PlayerManager.cs` — プレイヤーの移動と射撃、敵との接触判定
- `EnemyManager.cs` — 敵の定期スポーン(出現位置はランダム)
- `Bullet.cs` — 弾の移動、敵への命中処理(爆発・スコア加算)
- `GameManager.cs` — スコアの管理(シーンをまたぐシングルトン)
